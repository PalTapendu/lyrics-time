## Hero 1 Components

### Timing Console
```
#console
  .console-plane            ← CSS 3D transform target
    .main-card              ← Glare effect container (--glare-x, --glare-y CSS vars)
      .glass-extrusion      ← Behind card (translateZ depth layer)
      .console-contact-shadow
    .card-content
      .card-top-bar → Console header bar
      .waveform-panel
        #wf (SVG, 120 bars) ← Generated by script.js IIFE 1
        #ph (playhead line) ← translateX animated
        #tip (timestamp)    ← textContent updated
        #ax (SVG time axis) ← Generated by script.js IIFE 1
      .lyrics-card
        .lyrics-header
          #np (Now Playing badge) ← moves between rows
          #hl (highlight bar)     ← top position animated
        .lyrics-list
          .row (×6)               ← lyric rows with timestamps
            .row-dot
            .mw (SVG mini waveform)
            .row-time
            .row-text
      #pb (play/pause button)
      .main-upload-btn #main-upload-btn
```

**Key interactions**:
- `#pb` click → `togglePlayState()`
- `.waveform-panel` mousedown/drag → `seekFromEvent()` (timeline scrubbing)
- `.row` click → `setActiveLyricRow(row)` + seek + play

### Mini Piano Widget (`#mini-piano`)
Managed entirely by `piano.js`. Root element is `#mini-piano` inside `.lower-section`.

```
#mini-piano
  .piano-header-bar
    .piano-brand-label → "LIVE HARMONIC PIANO"
    .piano-mute-toggle → click = toggle mute (isMuted)
  .piano-key-container
    SVG #piano-keys-svg
      → 7 white keys + 5 black keys (drawn by piano.js JS)
  .piano-glow-canvas (Canvas 2D, key glow effect)
  .piano-auto-label → "Auto-Playing Demo..."
  .piano-octave-display → "C4–B4"
```

**Key API exposed by piano.js**:
```js
window.pianoTriggerKey(note, isBlack, isSongSync) // play a key by note name
window.activateLivePiano()  // unmute + play welcome chord + pulse animation
window.isHeroSongPlaying()  // check if hero audio is playing (for sync logic)
```

### Floating Elements (`.pz`)
All have `class="pz"` with `data-d` (parallax depth) and optional `data-r` (rotation):
- Headphones back: `data-d="14" data-r="0.8"` at left 1475, top 62 (`z-index: 5`)
- Headphones front: same position (`z-index: 18`)
- `#hand-top`: annotation arrow (top-right of console)
- `#hand-bottom`: annotation arrow (bottom of console)
- Organic petal SVG background: `data-d="-8"`

### Background Canvas (`#bg`)
Canvas 2D, 30 particles:
- 18 large ambient orbs (radial gradient blobs, color per music spectrum)
- 12 small warm sparkle particles (cream-colored, upward drift)
- Mouse repulsion at 220px radius

### Cursor Glow (`#glow`)
`<div id="glow">` — large semi-transparent disc, follows mouse smoothly via JS lerp.

## Toast Notifications

Two separate toasts:
- **`#toast`** — Hero 1, bottom-center, cream/green
- **`#heroToast`** — Hero 2, bottom-center, dark/green

Both use the same show/hide pattern:
```js
toast.classList.add('show'); // fade in
setTimeout(() => toast.classList.remove('show'), 3200); // fade out
```

## Products Dropdown

Pure CSS hover dropdown — no JS toggle:
```css
.nav-dropdown-wrap:hover .nav-dropdown-menu { display: block; opacity: 1; }
```

Dropdown item order (top → bottom):
1. `#dropdown-console-btn` — Sync Lyrics & Script (default active)
2. `#dropdown-visualizer-btn` — Audio Visualizer (has NEW badge)
3. `#dropdown-piano-btn` — Live Harmonic Piano
